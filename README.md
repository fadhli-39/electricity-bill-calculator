# House Electricity Bill Calculator

## Project Description
A PHP web application that calculates house electricity bills based on block tariffs.

## Features
- Electricity consumption input form
- Block tariff calculation
- Input validation
- Minimum monthly charge
- SST calculation
- Final bill display

## Technologies Used
- HTML
- CSS
- PHP

## How to Run
1. Install XAMPP.
2. Start Apache.
3. Place the project folder inside htdocs.
4. Open http://localhost/electricity_bill/ in your browser.
